# 여러 기기에서 함께 접속하기 — Firebase 설정 (한 번만)

설정 전에는 **시험 모드**로 돌아갑니다: 같은 컴퓨터·같은 브라우저의 여러 탭끼리만 서로 보여요.
아래 순서대로 한 번만 설정하면 교실의 여러 기기(학생 태블릿·노트북)가 같은 반 공원에 들어옵니다.

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 들어가 **프로젝트 추가** → 이름(예: `makepark`) → 애널리틱스는 꺼도 됩니다.

## 2. 익명 로그인 켜기
1. 왼쪽 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **익명** → 사용 설정 → 저장
   - 학생은 계정 없이 들어오고, 기기(탭)마다 보이지 않는 번호가 생겨요. 이 번호로 "내 캐릭터는 나만 움직이고, 모으기·내보내기·공원 닫기는 공원을 만든 선생님만" 할 수 있게 막습니다.

## 3. 실시간 데이터베이스 만들기
1. 왼쪽 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: **싱가포르(asia-southeast1)** 처럼 가까운 곳 → **잠금 모드로 시작**
3. **규칙** 탭에서 내용을 모두 지우고, 이 저장소의 `database.rules.json` 내용을 붙여 넣은 뒤 **게시**

## 4. 웹 앱 설정값 넣기
1. 프로젝트 개요 옆 톱니바퀴 → **프로젝트 설정** → 아래 **내 앱**에서 웹(`</>`) 앱 추가 → 이름 입력(호스팅은 체크하지 않아도 됨)
2. 나오는 `firebaseConfig` 값을 `js/net/firebase-config.js` 의 `window.MP_FIREBASE_CONFIG = { ... }` 에 붙여 넣기
3. `databaseURL` 이 들어 있는지 꼭 확인하세요(없으면 Realtime Database 화면 위쪽의 주소 `https://....firebasedatabase.app` 를 넣으세요).

> 웹용 Firebase 설정값은 브라우저로 그대로 전달되는 공개 식별자라 비밀번호가 아니에요. 대신 3번의 규칙이 쓸 수 있는 내용을 막습니다.

## 5. 써 보기
- 선생님: `teacher.html`(첫 화면 '어디로 갈까요?' 창 아래 **선생님이세요? 우리 반 공원 만들기**) → 이름 입력 → **공원 만들기** → 반 코드 5자리
- 학생: 첫 화면에서 닉네임·학년 → **공원으로 출발!** → 반 코드 입력 → **우리 반 공원 입장**
- 선생님 화면: 들어온 학생 목록·지도 위 위치, **모두 모으기**(분수 광장, 놀이기구 안에 있던 학생도 나옴), **내보내기**, **공원 닫기/다시 열기**

## 무료 사용량 참고 (Spark 요금제)
- 동시 접속 100명, 한 달 내려받기 10GB까지 무료예요.
- 학생 한 명이 걸을 때 위치를 1초에 5번까지 보내요(가만히 있으면 3초에 한 번). 30명 반이 한 시간 내내 계속 걸어 다니면 대략 1GB 안팎을 써요.
- 여러 반이 자주 쓰면 Blaze(쓴 만큼 내는) 요금제로 바꾸거나 `js/net/multiplayer.js` 의 `SEND_MS`(보내는 간격)를 늘리세요.
