# 메이크파크 크리스마스 이미지 패키지

## 포함 파일
- maps/base-map.png: 기존 일반 시즌 전체 지도 (1672×941).
- decorations/: 알파 투명 배경 장식 PNG 12종. 개별 여백 8px.
- assets.json: 파일명, 실제 크기, 기본 바닥 기준점.

## 클로드 코드에 전달할 지시
기존 맵을 배경으로 쓰고 decorations 폴더의 PNG를 별도 크리스마스 레이어에 배치하세요. christmasEnabled 값 하나로 장식을 모두 켜고 끄세요. 이미지를 CSS 도형이나 이모지로 대체하지 마세요. 종횡비를 유지하고 배경과 장식에 같은 좌표 변환을 적용하세요. 길과 건물 입구를 가리지 않도록 배치하세요. 캐릭터의 발 위치와 장식의 바닥 위치를 기준으로 앞뒤 순서를 정하세요. 벽에 붙는 리스·리본·가랜드·전구는 건물 장식 레이어에 고정하세요.

## 권장 배치
- 큰 트리: 분수 왼쪽 조경 구역. 지도 기준 가로 약 170~200px.
- 중간 트리와 화분 트리: 정문 양옆. 가로 약 35~55px.
- 눈사람: 광장 오른쪽 아래 화단. 가로 약 65~80px.
- 썰매: 레인보우 퍼레이드 앞 꽃차 부근. 가로 약 100~130px.
- 리스·리본: 정문 기둥 및 건물 처마. 간판 글자를 가리지 않도록 배치.
- 가랜드·전구: 건물 처마 폭에 맞춰 배치. 전구 반짝임은 코드에서 별도로 구현.
- 선물·화단·가로등: 트리 주변과 보행로 바깥 조경 구역.

## 시안과 구현 이미지의 구분
대화에 표시된 크리스마스 전체 지도는 완성 분위기를 보는 시안입니다. 이 ZIP에는 일반 시즌 기본 지도와 별도 장식 12종이 들어 있습니다. 시안의 지붕·잔디 위 눈은 이 12종에 포함되지 않으며, 동일하게 구현하려면 해당 부분의 눈 오버레이를 추가 제작해야 합니다. 실제 배치는 시안과 픽셀 단위로 일치하지 않습니다.

기본 지도에 제목과 건물 이름이 이미 그려져 있습니다. 현재 파일 위에 같은 이름을 다시 표시하지 마세요. 글자를 자유롭게 바꾸는 버전은 무문자 기본 배경을 별도로 제작해야 합니다. 지도 한 장은 큰 배율 확대 시 흐려질 수 있습니다. 충돌 영역, 입장 위치, 캐릭터와 애니메이션은 구현 단계에서 설정하세요.
