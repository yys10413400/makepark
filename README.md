# 메이크파크 (첫 플레이 버전)

초등학생용 2D 놀이공원 웹 게임. 이번 단계 범위: **공원 이동 → 시설 접근 → 입장 안내**.

## 실행 방법
설치는 필요 없습니다.
- 가장 간단한 방법: `index.html`을 브라우저로 엽니다.
- 로컬 서버로 열기(권장): 이 폴더에서 `python -m http.server 5178`를 실행한 뒤 http://localhost:5178 에 접속합니다.
- 개발용 디버그: 주소 뒤에 `?debug=1`을 붙이거나 게임 중 **F2**를 누르면 이동 영역(초록), 막힌 추출 영역(빨강), 손으로 고친 영역(점선), 입장 범위(노랑 원), 경로, 마우스 지도 좌표가 보입니다. `?debug=1`일 때 콘솔에서 `await MP_SELFTEST()`를 실행하면 자동 점검이 돌아갑니다.

## 조작
- 방향키 / WASD: 이동
- 길 클릭·터치: 길을 따라 그 위치로 이동합니다. 이동 중에 다른 곳을 누르면 바로 목적지를 바꿉니다.
- 시설 입구 근처: **입장하기** 버튼 또는 스페이스바 → 안내창. 닫기는 버튼, Esc, 스페이스바로 합니다.
- **전체 지도** 버튼(또는 M): 공원 전체 보기. 핀을 누르면 그 시설로 걸어갑니다.
- **계절** 버튼: 크리스마스 ↔ 일반 지도 전환(기본 크리스마스). 고른 계절은 기기에 저장되고, 위치·학년은 그대로 유지됩니다.

## 폴더 구조
| 경로 | 내용 |
|---|---|
| `js/data/park-data.js` | **수정용 데이터**: 시설(이름·소개·입구·입장 반경·지도 핀), 시작 위치, 이동 영역 수정(walkEdits), 카메라, 시즌 배경 |
| `js/data/walkmask.js` | 두 시즌 지도에서 **모두** 길인 칸만 남긴 공통 이동 격자(8px 칸). 아래 명령으로 다시 만듭니다. |
| `js/walkgrid.js` | 이동 격자와 A* 경로 탐색 |
| `js/character.js` | 캐릭터 그리기(**임시 캐릭터**). PNG 걷기 스프라이트로 바꾸는 방법은 파일 머리말에 있습니다. |
| `js/game.js` | 화면, 카메라, 입력, 시설 안내, 저장 |
| `assets/maps/makepark-christmas.png`, `makepark-normal.png` | 시즌 완성 지도(1672×941, 같은 배치). 모든 좌표의 기준입니다. |
| `assets/legacy/` | 이전 패키지의 기본 지도와 개별 장식 12종. 보관만 하고 화면에는 쓰지 않습니다. |

## 좌표계
모든 좌표는 기본 지도 원본 픽셀(1672×941, 왼쪽 위 0,0) 기준입니다. 배경, 캐릭터, 충돌 영역, 입구가 같은 변환 하나로 그려지므로 화면 크기가 바뀌어도 어긋나지 않습니다.

## 지도를 바꿨을 때
1. `assets/maps`의 지도 파일을 바꿉니다(같은 크기·같은 배치 권장).
2. 이동 격자 다시 만들기:
   `python tools/build_walkmask.py js/data/walkmask.js assets/maps/makepark-christmas.png assets/maps/makepark-normal.png`
3. `?debug=1`로 열어 시설 입구·핀 좌표를 확인하고, 콘솔에서 `await MP_SELFTEST()`로 점검합니다.

## 충돌 판정
캐릭터 발 위치를 중심으로 한 작은 사각형(`park-data.js`의 `foot`, 기본 14×6px)의 네 모서리가 모두 길 위일 때만 설 수 있습니다.

## 저장
닉네임, 학년, 계절, 마지막으로 이동할 수 있었던 위치를 브라우저 localStorage(`makepark.save.v1`)에 저장합니다. 저장된 위치가 이동 영역이 아니면 정문 안쪽에서 시작합니다.
