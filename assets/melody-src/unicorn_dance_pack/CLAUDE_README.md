# Make Park 유니콘 댄스 에셋

청록 갈기·크림 앞머리·청기와빛 도포·금빛 구름 자수 의상 기준.

- 모든 GIF/개별 PNG: 320×320, 투명 배경. 4프레임의 짧은 포즈 애니메이션 초안.
- step_left.gif / step_right.gif: 화면 기준 좌우 스텝, 500ms 반복.
- jump.gif: 500ms 한 번 재생 후 idle.png로 복귀.
- freeze.gif: 500ms 한 번 재생 후 마지막 PNG 유지.
- idle.png: 기본 대기 자세.
- animation.json: 프레임별 재생 시간과 동작 매핑.

## 구현 기준
같은 320×320 요소를 유지하고 object-fit:contain으로 표시. 이미지별 자동 크롭이나 크기 변경 금지. 방향은 화면 기준이며 캐릭터의 좌우가 아님. 의상·앞머리가 뒤집히므로 CSS scaleX(-1)로 반전하지 말 것.

게임 구현은 GIF보다 동봉 PNG 프레임과 animation.json을 사용하면 박자 동기화·재시작·멈춤을 정확히 제어할 수 있음. GIF는 동작 미리보기 및 간단한 적용용. 점프는 이미지 내부에 상승이 포함되어 있으므로 별도 큰 Y 이동을 중복 적용하지 말 것. 각 입력에 맞춰 애니메이션을 0번 프레임부터 시작하고 게임 오디오 시계를 기준으로 조정. freeze에서는 모든 동작을 멈추고 마지막 자세 유지.

이 자료는 4프레임 포즈 전환 버전으로, 부드러운 고프레임 애니메이션은 아님. GIF는 1비트 투명이므로 경계에 거침이 생길 수 있으며 실제 게임에는 반투명 경계를 보존하는 PNG 사용 권장.
