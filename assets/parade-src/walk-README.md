# 레인보우 퍼레이드 걷기 동작

압축을 풀고 preview.html을 브라우저에서 열면 샘플 현수막으로 행진을 볼 수 있어요.

- riri.png, momo.png, lulu.png는 각각 1792 × 896 투명 스프라이트 시트입니다.
- 프레임은 448 × 448, 가로 4칸 × 세로 2줄입니다. 위쪽부터 왼쪽에서 오른쪽으로 읽습니다.
- 미리보기는 프레임당 105ms를 사용합니다. 모모와 루루는 같은 프레임 번호를 공유합니다.
- 현수막 장대의 중심 x는 모모 330px, 루루 125px입니다. 스프라이트 왼쪽 위를 기준으로 잽니다.
- 미리보기는 양 끝과 상단을 고정하고 아래쪽 높이만 최대 3px 흔듭니다. 게임 적용 시 샘플 현수막 내용을 아이가 꾸민 Canvas로 교체하면 됩니다.
- 루루는 오른쪽을 보며 걷고, 몸 뒤쪽인 화면 왼편에서 장대를 잡습니다. 세 친구 모두 오른쪽으로 이동합니다.
