# 학생 앱·선생님 앱 설치하기

메이크파크는 두 개의 앱으로 나뉘어 있어요. 둘 다 같은 서버(Firebase)를 써서 서로 연결돼요.

| 앱 | 여는 주소 | 아이콘 | 하는 일 |
|---|---|---|---|
| **메이크파크** (학생) | `https://<게임 주소>/` | 하늘색 배경의 MAKE PARK 정문 | 닉네임·학년 → 반 코드·비밀번호로 반 공원 입장, 게임 |
| **메이크파크 선생님** | `https://<게임 주소>/teacher.html` | 보라색 배경 + '선생님' 띠 | 구글 로그인 → 내 반 목록 → 반 관리 |

학생 앱에는 선생님 화면으로 가는 링크가 없어요. 선생님 주소는 선생님만 알고 계시면 돼요.

## 설치 방법
앱 설치는 **https 주소**에서만 돼요(예: GitHub Pages). `index.html` 파일을 바로 열거나 `http://`로 열면 설치 버튼이 나오지 않아요(`localhost`는 시험용으로 예외).

- **크롬북·윈도우·맥 (Chrome / Edge)**
  - 학생 앱: 첫 화면 오른쪽 아래 **📲 앱으로 설치** 또는 주소창 오른쪽의 설치 아이콘
  - 선생님 앱: 선생님 화면 위쪽 **📲 선생님 앱으로 설치** 또는 주소창의 설치 아이콘
- **안드로이드 태블릿 (Chrome)**: 같은 버튼, 또는 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**
- **아이패드 (Safari)**: 공유 버튼 → **홈 화면에 추가** (이름·아이콘이 자동으로 들어가요)

설치하면 주소창 없이 열려요. 학생 앱은 가로 전체 화면이에요.

## 업데이트
GitHub에 올리면 다음에 앱을 열 때 자동으로 최신이 돼요. 인터넷이 끊겼을 때만 전에 받아 둔 파일로 열려요(`sw.js`).
아이콘을 바꾸려면 `python tools/build_icons.py` 를 다시 실행하세요(`assets/icons/`).
