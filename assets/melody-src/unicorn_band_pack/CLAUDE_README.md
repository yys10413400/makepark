# 메이크 파크 자유 연주 — 유니콘 밴드 10종

## 파일
각 폴더에 idle.png(준비), frame_00~03.png(준비→예비→연주→복귀), strip.png(4칸 가로 시트), play.gif(400ms 1회), preview_loop.gif(감상용 반복)가 있습니다.
모든 개별 프레임은 투명 320×320, 가로 시트는 1280×320. preview.html을 브라우저에서 열어 확인할 수 있습니다. 소리는 포함하지 않으며 기존 게임의 오디오에 연결합니다.

## 매핑
bass_drum=큰북/갈색, small_drum=작은북/주황 머리띠, clap=박수/분홍, bells=방울/은색, do_keyboard=도/빨강 건반, re_guitar=레/주황 기타 선글라스, mi_trumpet=미/노랑 트럼펫, sol_sax=솔/초록 베레모 색소폰, la_violin=라/파랑 바이올린, high_do=높은 도/청록 주인공. 도레미솔라높은도 구성을 유지하며 파와 시를 임의로 추가하지 않습니다.

## 연동 지침
평소에는 idle.png. 해당 음이 울리는 순간 PNG 애니메이션을 1회 실행한 뒤 idle로 복귀. 같은 캐릭터가 다시 연주하면 이전 예약을 취소하고 새 동작으로 재시작. 다른 캐릭터 타이머에는 영향 주지 말 것. 편집/정지/화면 이탈 시 타이머 모두 정리.
프레임 시간은 animation.json: 80,80,140,100ms 총400ms. 강한 연주 자세는 frame_02이므로 정확한 소리 동기화가 필요하면 발음 시점에 frame_02을 표시하고 frame_03→idle로 복귀하거나, 예정된 발음 160ms 전에 예비동작을 시작합니다.
GIF는 간단 미리보기용이며 브라우저에서 재시작/정밀 제어가 어려우므로 실제 게임은 PNG 권장. play.gif는 반복하지 않고 마지막 프레임에 남습니다.
크기는 고정하고 object-fit:contain 사용. 개별 자동 크롭 금지. 좌우 반전 금지. 프레임별 생성이므로 세부 형태가 약간 달라질 수 있는 4프레임 초안입니다. GIF는 1비트 투명 경계, PNG는 반투명 경계를 보존합니다. 실제 배경 위에서 크기와 위치를 조절해 확인하세요.
