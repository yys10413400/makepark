# 메이크파크 (첫 플레이 버전)

초등학생용 2D 놀이공원 웹 게임. 이번 단계 범위: **공원 이동 → 시설 접근 → 입장 안내**.

## 실행 방법
설치는 필요 없습니다.
- 가장 간단한 방법: `index.html`을 브라우저로 엽니다.
- 로컬 서버로 열기(권장): 이 폴더에서 `python -m http.server 5178`를 실행한 뒤 http://localhost:5178 에 접속합니다.
- 개발용 디버그: 주소 뒤에 `?debug=1`을 붙이거나 게임 중 **F2**를 누르면 이동 영역(초록), 막힌 추출 영역(빨강), 손으로 고친 영역(점선), 입장 범위(노랑 원), 경로, 마우스 지도 좌표가 보입니다. `?debug=1`일 때 콘솔에서 `await MP_SELFTEST()`를 실행하면 자동 점검이 돌아갑니다.

## 조작
- 방향키 / WASD: 이동
- 길 클릭·터치: 길을 따라 그 위치로 이동합니다. 이동 중에 다른 곳을 누르면 바로 목적지를 바꿉니다.
- 시설 입구 근처: **입장하기** 버튼 또는 스페이스바 → 안내창. 닫기는 버튼, Esc, 스페이스바로 합니다.
- **미니맵**(오른쪽 위): 내 위치(빨간 점)·친구(파란 점)·선생님(노란 점)과 지금 보이는 곳(흰 네모). 누르면(또는 M) 전체 지도로 크게 펼쳐지고, 핀을 누르면 그 시설로 걸어갑니다.
- 이름 밑 **티켓 수**: 코스터·유령의 집에서 받은 티켓(캐릭터 가게에서 씀).
- **계절**: 반 공원은 선생님이 선생님 화면에서 고른 계절(크리스마스·일반)로 모든 학생 화면이 같이 바뀝니다. 혼자 둘러보기는 기본 계절(크리스마스).
- **대화**(반 공원에서만, 화면 아래): 이모지 6개와 '💬 말하기'의 정해진 문장 10개만 골라 말해요. 캐릭터 머리 위에 말풍선이 4초 뜨고, 다음 말은 2초 뒤에. 글자를 직접 쓰지 않고 번호만 주고받으며(`players/{pid}`의 `sy`·`st`), 기록은 남기지 않아요. 선생님 화면에서 **학생 대화**를 끄면 학생은 말할 수 없어요(선생님은 말할 수 있음).

## 캐릭터
처음 들어올 때 기본 남자아이(F1)·여자아이(F2) 중 하나를 고르고, 공원 위쪽 **캐릭터** 버튼에서 언제든 바꿉니다.
- **건물 보상**(R1~R7): 건물(스테이지)을 통과하면 받습니다. 지금은 코스터 익스프레스만 미션이 있어, 코스터 학년 과정 스탬프를 받으면 꼬마 기관사가 열립니다. 남자아이·여자아이 그림이 따로 있고, 마지막으로 고른 기본 캐릭터의 성별 쪽을 씁니다.
- **티켓 가게**(S1~S10): 티켓 20·30·40장으로 삽니다. 한 번 누르면 확인, 한 번 더 누르면 삽니다.
- 저장: `makepark.save.v1`의 `character = { id, gender, owned }`, 티켓은 `tickets`.
- 시험: `characters-test.html`에서 26명이 네 방향으로 걷는 모습을 한 번에 봅니다. 게임은 `index.html?test=1`로 열면 모든 캐릭터를 티켓·건물 통과 없이 골라 볼 수 있습니다(티켓·보상 기록은 그대로).
- 그림: 원본(`assets/characters-src/*.png`)에서 `python tools/build_characters.py`가 배경을 지우고 앞·뒤·옆 3칸으로 잘라 몸 키를 맞춥니다(모자 높이 보정 `HAT`, 왼쪽을 보는 옆모습은 `SIDE_FACES_LEFT`로 뒤집음). 왼쪽으로 걸을 때는 게임에서 옆모습을 뒤집어 그립니다.
- 걷기: 걷기 칸 그림 없이 걸음마다 살짝 위아래로 움직이고, 옆모습은 가는 쪽으로 조금 숙여 걷습니다(`js/characters.js`의 `Walker.draw`). 지도 위 몸 키는 `DRAW_H`(60px).
- 걷기 GIF: 기본 남녀(F1·F2)와 건물 보상 R1~R5(남녀)는 제미나이 걷기 GIF(`assets/characters-src/gif/<id>-walk.gif`)에서 끝과 시작이 이어지는 한 걸음(12~17장)을 뽑아 그대로 재생합니다. `python tools/build_char_anim.py`가 `assets/characters/<id>-anim.webp`를 만들고(앞모습 키를 서 있는 그림에 맞춤, 절반 크기 저장), GIF가 없는 캐릭터는 아래 걷는 자세 그림으로 걷습니다.
- 걷는 자세 그림: 24명(기본 남녀·건물 보상·티켓 가게, `build_walk.py`의 `LEGS`)은 걷는 자세가 있어 [걷는 자세, 서 있기, 반대 발, 서 있기]로 걷습니다. 옆모습은 서 있는 그림을 제미나이에 올려 '다리·팔만 걷는 자세로' 고쳐 받은 원본(`assets/characters-src/walk/<id>_side.png`)을 쓰고, 앞·뒤는 서 있는 그림에서 한쪽 종아리를 살짝 들어 올려 만듭니다(제미나이 그림은 안짱다리처럼 나와서). `python tools/build_walk.py`로 `assets/characters/<id>-walk.webp`를 만들고, 앞·뒤 반대 발은 좌우로 뒤집어 씁니다. 천에 다리가 가려진 꼬마 유령만 걷는 자세 없이 코드로만 걷고, 마법사·공주님은 옷자락 아래 신발만 들어 올립니다(`LEG_BY`).

## 좌표계
모든 좌표는 시즌 지도 원본 픽셀(1448×1086, 왼쪽 위 0,0) 기준입니다. 배경, 캐릭터, 충돌 영역, 입구가 같은 변환 하나로 그려지므로 화면 크기가 바뀌어도 어긋나지 않습니다.

## 지도를 바꿨을 때
1. `assets/maps`의 지도 파일을 바꿉니다(같은 크기·같은 배치 권장).
2. 이동 격자 다시 만들기:
   `python tools/build_walkmask.py js/data/walkmask.js assets/maps/makepark-christmas.webp assets/maps/makepark-normal.webp`
3. `?debug=1`로 열어 시설 입구·핀 좌표를 확인하고, 콘솔에서 `await MP_SELFTEST()`로 점검합니다.

## 충돌 판정
캐릭터 발 위치를 중심으로 한 작은 사각형(`park-data.js`의 `foot`, 기본 10×4px)의 네 모서리가 모두 길 위일 때만 설 수 있습니다. 이동 격자는 4px 칸이고, 방향키 이동은 2px씩 나눠 움직이며 막히면 비스듬히 또는 옆으로 비켜 미끄러집니다.

## 건물 뒤로 지나가기(앞뒤 순서)
`park-data.js`의 `occluders`에 건물·정문마다 영역과 바닥선(`baseY`)을 적어 둡니다. 캐릭터 발이 바닥선보다 위(북쪽)에 있으면 그 영역의 그림을 캐릭터 위에 다시 그려서 건물 뒤에 있는 것처럼 보입니다. 길 색 픽셀은 투명하게 빼므로 건물·나무만 덮습니다. 가려진 동안에는 캐릭터의 흐린 윤곽이 보입니다.
`walkUnder`는 건물 위쪽 길 가장자리에서 그만큼 아래까지를 '건물에 가려진 길'로 보고 걸을 수 있게 합니다. 정문 아치 아래, 매표소·마이파크 문 뒤의 길은 `walkEdits`로 열었습니다.

## 지도 선명도(AI 업스케일)
게임에 쓰는 지도는 받은 2배 지도(`maps-src/*-2x-original.png`)를 Real-ESRGAN `realesrgan-x4plus` 모델로 4배 키운 뒤 다시 2배 크기(2896×2172)로 줄인 것입니다(`maps-src/*-2x-ai.png`). 크기는 그대로이고 선과 글자가 또렷해집니다.
도구: github.com/xinntao/Real-ESRGAN 공식 배포판 `realesrgan-ncnn-vulkan-20220424-windows.zip` (저장소에는 넣지 않음)
`realesrgan-ncnn-vulkan.exe -i 2x-original.png -o x4.png -n realesrgan-x4plus -s 4` → 2896×2172로 LANCZOS 축소 → `python tools/redo_signs.py`(간판 글씨 지우고 다시 쓰기) → WebP 94

## 간판 글씨
간판 11개 글씨는 `tools/redo_signs.py`로 지우고 다시 씁니다: 간판 바탕(크림/보라)에 둘러싸인 글자 픽셀만 골라 둘레 바탕색으로 부드럽게 메운 뒤(덮개 없이), 간판 판의 정중앙에 글자만 둥근 글씨체(Cafe24 써라운드, 이 PC에 설치된 글꼴 사용)로 씁니다. 테두리·장식은 건드리지 않습니다. 아래 `rewrite_signs.py`는 예전 1배 지도용입니다.
지도 그림의 간판 글씨 11개는 `tools/rewrite_signs.py`로 지우고 맑은 고딕 Bold로 다시 썼습니다. 원본 그림(1배·2배)은 `assets/maps-src`에 있습니다. 2배 지도는 1배 원본에서 글자 위치를 찾아 씁니다:
`python tools/rewrite_signs.py assets/maps-src/makepark-christmas-2x-original.png out.png assets/maps-src/makepark-christmas-original.png` (결과를 WebP 품질 94로 저장)
글자를 바꾸려면 `SIGNS`의 글자를 고친 뒤 두 지도에 다시 실행하세요.

## 입장 화면과 프로필
가로 화면(폭 720px 이상, 높이 520px 이상, 가로가 더 긴 화면)에서는 받은 시안 그림(`assets/ui/entry-screen.webp`)에서 오려 낸 패널(`entry-panel.webp`)을 화면 높이의 72% 크기로 공원 지도 위 가운데에 띄웁니다. 그 위 정확한 자리에 투명한 실제 입력칸·학년 버튼·출발 버튼을 올립니다. 세로 핸드폰 화면에서는 그림이 너무 작아져 누르기 어려우므로 같은 디자인을 CSS로 만든 화면을 씁니다.
닉네임(앞뒤 공백 제거, 1~12글자)과 학년(1~6, 첫 방문은 미선택)을 입력하면 공원으로 들어갑니다. 공원 안에서는 왼쪽 위 닉네임을 누르면 닉네임과 학년을 바꿀 수 있습니다(취소하면 그대로).
학년군: 1~2학년 low, 3~4학년 middle, 5~6학년 high (`state.gradeBand`). 코스터 익스프레스가 이 학년군으로 과정을 고릅니다.

## 저장
닉네임, 학년, 마지막으로 이동할 수 있었던 위치를 브라우저 localStorage(`makepark.save.v1`)에 저장합니다. 프로필을 바꿔도 다른 값(앞으로 생길 티켓·스탬프·작품 포함)은 그대로 둡니다. 저장값이 깨져 읽을 수 없으면 `makepark.save.v1.broken`에 원본을 보관한 뒤 새로 시작합니다. 저장이 안 되는 환경에서는 이번 방문 동안만 기억합니다. 저장된 위치가 이동 영역이 아니면 정문 안쪽에서 시작합니다.

## 코스터 익스프레스 (코딩 놀이기구)
공원에서 코스터 입구에 가서 입장하면 열립니다. 명령 버튼을 눌러 `내 명령`에 쌓고, `실행` 또는 `한 단계씩`으로 열차를 도착역까지 보냅니다. 설계표: `docs/coaster-missions.md`.
- **별 3개**: 도착 / 블록 par개 이하 / 보너스(별 모으기·손님 모두 태우기·빠르게 도착). 새로 받은 별 하나마다 티켓 5장(미션당 최대 15장). 다시 해서 별을 늘릴 수 있습니다.
- **장치**: 별(지나가면 모음), 갈림길(돌기로 길 고르기), 오르막(빠르게여야 올라감)·커브(천천히여야 들어감), 손님(그 칸에서 태우기, 매번 자리가 바뀌는 미션도 있음), 신호.
- **블록**: 앞으로, 왼쪽·오른쪽 돌기, 빠르게, 천천히, 손님 태우기, 기다리기, 반복, 만약(신호 초록 / 손님 있음).
- **과정**: 공통 `첫 출발` 다음 학년군 과정 4미션 — 1~2학년(순서·돌기·갈림길·고치기), 3~4학년(속도·반복), 5~6학년(손님·만약·반복+조건). 과정을 모두 도착하면 스탬프.
- 저장: `makepark.save.v1`의 `tickets`, `coaster`(`done` 도착, `best` 최고 별, `paid` 받은 티켓, `programs` 미션별 마지막 명령, `stamps`).
- 미션 확인: `node tools/verify_coaster.js`
- 화면 좌표: 빈 화면 그림(1672×941) 기준 퍼센트로 버튼·글자·레일을 놓아 창 크기가 바뀌어도 같이 커지고 작아집니다.

## 유령의 집 — 문지기의 비밀 규칙 (규칙 추리 놀이)
공원에서 유령의 집에 입장하면 보랏빛 저택 로비가 열립니다. 공원에서 고른 캐릭터로 걸어(방 그림에 맞게 공원 화면 크기의 1.3배, 안쪽은 작게·앞쪽은 크게. 로비에서만 방 조명 색을 입히고 부드러운 그림자와 바닥 반사를 그림)(방향키·바닥 클릭) 문 앞 문지기 유령에게 가면 **말 걸기**(스페이스)가 뜹니다. 로비 아래 카펫으로 내려가거나 **공원으로**를 누르면 유령의 집 입구 앞으로 돌아갑니다.
- 대화: 공원 학년이 기본으로 골라져 있고, 다른 학년 난이도도 고를 수 있습니다(이번 놀이에만 적용).
- 화면: 왼쪽 벽에 가로 손님 기록판(왼쪽 두 칸 통과, 오른쪽 두 칸 잠깐!), 그 아래 **판정한 손님** 줄에 판정을 끝낸 손님이 왼쪽부터 하나씩 쌓입니다. 오른쪽 황금문 앞에 손님, 그 옆에 유령, 아래 카운터 위에 통과·잠깐! 버튼.
- **혼자 추리하기 = 3단계**(단계마다 규칙 하나, 손님 3명)
  - 코스터처럼 판마다 **새 문제**: 학년마다 배울 틀은 그대로 두고 어떤 단서인지(배지·소품, 어느 쪽이 먼저인지)는 무작위, 바로 전 판 문제는 피함(`gate.last`에 저장). 3~4학년부터 1·2단계에도 빈손, 5~6학년은 배지 없음도 단서로 나와요. 3단계는 1·2단계에 나온 단서를 다시 쓰지 않아요.
  - 1단계: 배지 하나만 보기(예: 별 배지면 통과) / 2단계: 손 소품 하나만 보기(예: 호박등을 들면 통과)
  - 3단계: 1~2학년 다른 한 가지(별·달 × 열쇠·호박등 4가지 모습만), 3~4학년 **그리고**(둘 다, 빈손도 나옴), 5~6학년 **또는**(하나만 있어도)·**~만 빼고 모두**(배지 없음·빈손까지)
  - 틀리면 **돋보기 힌트**: 정답 대신 볼 곳 하나(예: "달 배지를 단 손님들을 봐! 모두 어느 쪽에 있지?")를 말하고 그 카드들이 빛납니다.
  - 단계가 끝나면 **내 규칙이 뭘까?** 그림 카드 3개 중 고르기(맞히면 보너스 별). 퀴즈와 규칙 공개 창은 기록판 아래 '판정한 손님' 줄 위에 떠서 기록판을 보면서 고를 수 있습니다. 이어서 규칙을 그림 공식(⭐ + 🔑 → 통과)과 문장으로 보여 주고, 기록 카드에서 규칙에 쓰인 배지·소품이 반짝입니다.
  - 3명 연속 정답이면 유령이 신나서 별이 터지고, 통과 손님은 "야호!", 잠깐 손님은 "히잉…" 하고 떠납니다.
  - 처음 한 번은 **어떻게 놀아요?**(배지·손 소품만 보기 → 통과 손님끼리 같은 점 찾기 → 맞으면 통과)를 먼저 보여 주고, 게임 중 **? 어떻게 해요**로 다시 볼 수 있습니다.
- 공정성: 기록 4장만으로 그 단계 규칙 후보가 하나로 정해지게 고르고, 지금 보이는 기록과 맞는 후보가 모두 같은 답을 내는 손님만 냅니다(아니면 기록을 한 장 더 꺼내 판정한 손님 줄에 보여 줌).
- **친구랑 문지기**: 친구 1이 카드로 규칙을 만들고(1~2학년 카드 1장, 3~4학년 + 그리고, 5~6학년 + 또는·~만 빼고) **규칙 봉인하기** → 편집 화면이 사라지고 "이제 문지기 친구에게 기기를 건네줘!" → 친구 2가 **준비됐어**를 눌러 손님 4명 판정 → 규칙 맞히기 → 공개 → **역할 바꾸기**.
- 보상(코스터와 같은 방식): 학년마다 혼자 추리하기를 처음 끝내면 티켓 3장, 그 뒤 새 문제 판(혼자·친구랑 문지기)을 끝낼 때마다 1장 — **하루 최대 5장**. 규칙 맞히기 별은 결과 화면에 자랑거리로만 보여요. 혼자 놀기를 처음 끝내면 건물 보상 **꼬마 유령**이 열립니다. 저장: `makepark.save.v1`의 `gate = { howto, cleared, rounds, best, done(학년별 첫 완료), day(오늘 받은 새 문제 티켓), last(바로 전 판 문제) }`.
- 그림: 카드 조합마다 그림을 따로 만들지 않고 기본 남녀 그림(전신=문 앞 손님, 상반신=기록 카드) 위에 배지(티셔츠 가운데)와 소품(화면 오른쪽 쥔 손)을 겹칩니다. 머리핀·신발 색은 손님마다 바꾸지만 판정에는 쓰지 않습니다.
- 점검: `node tools/verify_gatekeeper.js` (학년별 3단계 × 300판, 친구 모드 카드 조합 전부: 공정성·판정·힌트·새 모습 손님·통과/잠깐 손님·퀴즈 정답이 하나뿐인지)

## 함께하기 (여러 명이 같은 반 공원에)
- 학생: 첫 화면에서 닉네임·학년 → **공원으로 출발!** → **어디로 갈까요?** 창에서 반 코드(5자리)로 **우리 반 공원 입장** 또는 **혼자 둘러보기**. 마지막 반 코드는 기억해 둡니다.
- 공원에서: 같은 반 친구가 자기 캐릭터로 걸어 다니고 머리 위에 닉네임이 보여요(내 이름표는 초록). 위쪽에 `🏫 반 코드 · 친구 N명`. 놀이기구 안에 있는 친구는 공원에서 보이지 않아요.
- 선생님: `teacher.html` — **Google 계정으로 로그인**(시험 모드는 이름으로) → **내 반** 목록(여러 학교·여러 반, 반 이름·반 코드·열림/닫힘·학생 수) → 새 반 만들기 / 반 열기. 반 관리: 반 코드, 들어온 학생 목록·지도 위 위치, **모두 모으기**(분수 광장으로, 놀이기구 안에 있던 학생도 나옴), **내보내기**, **공원 닫기/다시 열기**, 반 이름 바꾸기, 이 반 없애기. 어느 컴퓨터에서든 같은 선생님 계정이면 내 반을 관리해요(다른 선생님 반은 보기만).
- 연결: `js/net/net.js`(MPNet). `js/net/firebase-config.js` 에 Firebase 설정값이 있으면 Firebase 실시간 데이터베이스(익명 로그인 + `database.rules.json` 규칙), 없으면 **시험 모드**(같은 브라우저 탭끼리, BroadcastChannel). 설정 순서: `docs/firebase-setup.md`
- 학생 쪽 화면: `js/net/multiplayer.js`, `css/net.css` / 선생님 화면: `teacher.html`, `js/net/teacher.js`, `css/teacher.css`
- 보내는 정보: 닉네임·학년·캐릭터·위치·방향·걷는 중·있는 곳(공원/놀이기구). 채팅은 아직 없어요.
- **반 기록(서버 저장)**: 반 공원에 처음 들어올 때 닉네임마다 비밀번호 4자리를 정하고, 그 학생의 캐릭터·티켓·놀이기구 기록이 반 공원에 저장돼요(2.5초마다 모아서 자동 저장). 다른 기기에서도 같은 반 코드·닉네임·비밀번호로 이어 해요. 반 공원에 있는 동안에는 기기 기록 대신 반 기록 칸(`makepark.class.<반코드>.<학생>`)을 쓰고, 나가면 그 기기의 원래 기록(`makepark.save.v1`, 혼자 둘러보기용)으로 돌아와요.
- 선생님 화면 **공원 계절 · 학생 대화**: 반 공원 정보(`rooms/{반코드}/meta`)의 `season`·`chatOff`. 처음 쓸 때는 Firebase 규칙에 `database.rules.json`을 다시 게시해야 해요(안 하면 '바꾸지 못했어요: PERMISSION_DENIED').
- 화면 시험: 주소 뒤에 `?netlocal=1`을 붙이면 Firebase 설정이 있어도 서버 없이 같은 브라우저 탭끼리만 함께 봐요(`teacher.html?netlocal=1`·`index.html?netlocal=1`).
- 선생님 화면 **우리 반 학생 기록**: 닉네임·학년·티켓·마지막 저장, 비밀번호 다시 정하기, 우리 반 기록 모두 지우기(학년 끝에만). 선생님은 창을 닫았다 열어도 같은 선생님으로 기억돼 공원 관리를 계속해요.
- 서버 경로: `rooms/{반코드}/names`(등록된 닉네임) · `students/{학생}`(비밀번호·기록, 본인과 선생님만 읽기) · `claims/{기기}`(비밀번호 확인 — 규칙이 맞을 때만 그 학생 기록을 열어 줌)
