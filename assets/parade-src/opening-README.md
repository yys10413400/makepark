# 리리의 퍼레이드 오프닝

압축을 풀고 preview.html을 열면 동작을 재생할 수 있어요.

riri-opening.png는 투명 배경의 2560 × 1280 PNG입니다.
640 × 640 칸 8개가 가로 4칸 × 세로 2줄로 배치되어 있습니다. 위쪽 줄부터 왼쪽에서 오른쪽으로 읽습니다.

| 프레임 | 자세 | 표시 시간 |
| --- | --- | --- |
| 0 | 인사 준비 | 220 ms |
| 1 | 자락을 잡고 고개를 낮추기 | 110 ms |
| 2 | 깊게 인사 | 290 ms |
| 3 | 고개를 조금 들기 | 135 ms |
| 4 | 몸을 일으키며 꼬리 펼치기 시작 | 110 ms |
| 5 | 꼬리를 반쯤 펼치기 | 130 ms |
| 6 | 꼬리를 더 펼치며 날개 들기 | 125 ms |
| 7 | 꼬리를 활짝 펴고 카트 맞이하기 | 760 ms |

한 번 재생한 뒤 마지막 포즈를 유지합니다. 시작 후 1120 ms에 첫 카트를 출발시키면 리리가 날개를 내미는 포즈와 맞아요.

Canvas 게임에서는 riri-opening.mjs의 drawRiriOpening을 가져와 사용하세요. PNG 로드가 끝나면 게임의 렌더링 루프에서 호출합니다.

```js
import { drawRiriOpening } from './riri-opening.mjs';

// sheet는 로드된 riri-opening.png 이미지입니다.
// elapsedMs는 퍼레이드 시작 후 경과한 시간입니다.
drawRiriOpening(context, sheet, elapsedMs, x, y, 320);
```

x, y는 320 × 320 출력 칸의 왼쪽 위 좌표입니다. 원본 640 픽셀 칸에서 발 기준점은 (320, 608)입니다. 게임에서 개별 PNG가 필요하면 시트를 640 × 640 칸으로 자르세요.
